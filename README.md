# 🔧 Site de Oficina

Site criado para uma oficina, para os clientes conhecerem os serviços e entrarem em contato direto pela própria página.

## 🚀 O que tem no site?
- Página inicial com apresentação da oficina
- Lista de serviços oferecidos
- Galeria com fotos dos serviços
- Horário de funcionamento e localização
- Área de contato para pedir orçamento

## 🛠️ Serviços
- Troca de óleo e filtros
- Freios e suspensão
- Revisão completa
- Motor e câmbio
- Elétrica e bateria
- Funilaria e pintura

## 📞 Como entrar em contato
O contato é feito diretamente pelo site, na seção de contato / orçamento.

É só preencher nome, serviço que precisa e enviar que a oficina responde.

## 💻 Tecnologias usadas
- HTML, CSS e JavaScript

## 🌐 Como acessar
Abra o site pelo link do projeto e navegue pelas seções para ver os serviços e entrar em contato.
